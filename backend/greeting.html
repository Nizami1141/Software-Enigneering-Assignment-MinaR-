MinaR Clearance Reports

MinaR helps demining coordinators and analysts track field progress. This prototype lets users create, review, and manage fictional progress reports.

Open interactive API docs

Available endpoints

  • GET/api/v1/clearance-reports

    List reports you can access.

  • GET/api/v1/clearance-reports/{id}

    Read one report.

  • POST/api/v1/clearance-reports

    Create a report.

  • PUT/api/v1/clearance-reports/{id}

    Replace a report’s editable fields.

  • DELETE/api/v1/clearance-reports/{id}

    Delete a report.

  • GET/api/v1/greeting

    View the project and team overview.
